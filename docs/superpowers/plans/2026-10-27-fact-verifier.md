# Fact Verifier Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the dataset builder, the offline scorer and the Colab notebook for a fine-tuned Qwen3.5-4B verifier that labels ckpt100's extracted facts, then run it against the pre-registered bar.

**Architecture:** `verifier_data.py` turns the dpo4 captures plus Opus labels into chat records (system = verifier instructions, user = chunk + numbered facts, assistant = JSON labels), split by article group. `notebooks/distill_verifier.ipynb` (generated by `build_verifier_nb.py`) trains a LoRA adapter on Colab, selects the lowest-dev-loss checkpoint (`verifier_select.py`, embedded verbatim), and writes test predictions. `verifier_eval.py` scores those predictions locally against Opus's labels under two drop policies and the bar.

**Tech Stack:** Python 3.12, `uv`, pytest, stdlib only in `scripts/distill`; Colab notebook on Unsloth + TRL `SFTTrainer`.

**Spec:** `docs/superpowers/specs/2026-10-27-fact-verifier-design.md`

## Global Constraints

- No API spend. Labels already exist; training runs on the user's Colab.
- Data stays in `/home/openclaw/Documents/Shared/projects/graph-rag-distill/`, never in the repo (the repo and GHCR image are public).
- HF token only via the `HF_TOKEN` environment variable or ssh stdin; never on a command line, never written to disk, never printed.
- Base model `Qwen/Qwen3.5-4B`; LoRA r=16, alpha 16, dropout 0, modules `q_proj k_proj v_proj o_proj gate_proj up_proj down_proj`; lr 2e-4, cosine, warmup 0.03, 2 epochs, `MAX_SEQ_LENGTH` 20480; eval and save every 25 steps; `save_total_limit=None`.
- Split: dpo4's `split_of(group, 0.2)` -> `"val"` becomes **test**; of the rest, a seeded 5% of groups becomes **dev**.
- Bar (spec section 6): catch rate >= 0.50, false-drop rate <= 0.02, parse failures <= 1% of replies. P1 preferred when both policies pass.
- Dataset revision `carev01/ft-opus-distill@verifier1` (private); adapter repo `carev01/qwen35-4b-graphrag-verifier` (private), revision `verifier1-ckpt<step>`.
- CI gate: `uv run ruff check src tests` (E7 on: no semicolons in tests, imports at top), `uv run mypy src`, `uv run --extra dev pytest -m "not live"`. Run `uv run ruff check scripts/distill tests/unit` on every task too.
- Never write `content or ""` to coerce an empty model reply (memory: llm-empty-reply-coerced-to-value). An empty or unparseable prediction is a counted parse failure.

## Review Focus

1. A capture reply whose label list length differs from its edge count, or that has no label at all, must be skipped and counted, never crash or misalign. Pinned in Task 1 (`test_build_record_skips_count_mismatch`, `test_main_counts_unlabelled`).
2. A predictions file that misses a test call id, or repeats one (a resumed notebook can write a reply twice), must not crash. A missing reply counts as a parse failure that keeps every fact; for a repeat, the first reply wins and repeats are counted. Pinned in Task 3 (`test_score_missing_and_duplicate_predictions`).
3. A reply wrapped in a code fence, with trailing prose, or empty must be a parse failure (strict JSON), counted, keeping all facts. Pinned in Task 3 (`test_parse_reply_rejects_fences_prose_and_empty`).
4. A reply whose `n` values repeat, skip or fall outside 1..N, or whose verdict is unknown, must be a parse failure. Pinned in Task 3 (`test_parse_reply_rejects_bad_numbering_and_verdicts`).
5. A quote that differs from the chunk only by whitespace (newlines, non-breaking spaces) must pass P1's quote check; a paraphrased quote must fail it. Pinned in Task 3 (`test_p1_quote_whitespace_and_paraphrase`).

```python
"""Fact-verifier dataset (spec docs/superpowers/specs/2026-10-27-fact-verifier-design.md
section 3). One chat record per ckpt100 `extract_edges.edge` reply:

  system     VERIFIER_INSTRUCTIONS (the labelling brief's definitions, shorter output)
  user       PREVIOUS MESSAGES + CURRENT MESSAGE + DOCUMENT CONTEXT + numbered FACTS,
             facts in reply order -- production builds the same text from the same call
  assistant  {"labels": [{"n", "verdict", "quote" | "category"}]}

Labels are Opus's final ones (`dpo_coverage.final_label`). Disputed facts and `stated`
facts whose quote is not in the chunk are left out of the FACTS list, so the model never
trains on an uncertain label. Split by article group: dpo4's val articles are the test
set; a seeded share of the rest is dev, written as val.jsonl.

    uv run --extra dev python -m scripts.distill.verifier_data \\
        --capture D3/capture-run/capture-v2.jsonl --capture D/capture-run/capture-v2.jsonl \\
        --labels D/store/label-opus --recheck D/store/recheck-opus --out D/verifier1
"""
from __future__ import annotations

import argparse
import hashlib
import json
from collections import Counter
from pathlib import Path

from scripts.distill.dpo_coverage import classify, current_message, final_label
from scripts.distill.dpo_labels import (LABEL_INSTRUCTIONS, load_answers, load_recheck,
                                        read_records)
from scripts.distill.dpo_pairs import fact_line, split_of, tag
from scripts.distill.teacher import AnswerStore

PROMPT_NAME = "verify_edges"
_OUTPUT = """Return only JSON: {"labels": [{"n": <fact number>, "verdict": "...", "category": "..."
(unsupported only), "quote": "..." (stated only)}]} with exactly one entry per fact, in order.
"""
VERIFIER_INSTRUCTIONS = LABEL_INSTRUCTIONS.split("Return only JSON:")[0] + _OUTPUT
SPLIT_FILES = {"train": "train.jsonl", "dev": "val.jsonl", "test": "test.jsonl"}


def verifier_user(rec: dict, facts: list[str]) -> str:
    u = rec["messages"][1]["content"]
    numbered = "\n".join(f"{n}. {f}" for n, f in enumerate(facts, 1))
    return "\n\n".join(["PREVIOUS MESSAGES:\n" + tag(u, "PREVIOUS_MESSAGES"),
                        "CURRENT MESSAGE:\n" + tag(u, "CURRENT_MESSAGE"), rec["context"],
                        "FACTS:\n" + numbered])


def build_record(rec: dict, labels: list[dict], recheck: dict[int, dict]) -> tuple[dict | None, Counter]:
    edges = rec["payload"]["edges"]
    if len(labels) != len(edges):
        return None, Counter({"label_count_mismatch": 1})
    current = current_message(rec)
    rl = classify(labels, recheck, current)
    why: Counter = Counter()
    keep: list[int] = []
    finals: list[str] = []
    entries: list[dict] = []
    for i in range(len(edges)):
        final = final_label(rl, i)
        if final == "disputed":
            why["disputed"] += 1
            continue
        if final == "stated" and not rl.verified[i]:
            why["stated_unverified"] += 1
            continue
        n = len(keep) + 1
        if final == "stated":
            entry = {"n": n, "verdict": "stated", "quote": labels[i]["quote"]}
        elif final == "confirmed":
            entry = {"n": n, "verdict": "unsupported",
                     "category": recheck.get(i, {}).get("category") or labels[i].get("category")}
        else:
            entry = {"n": n, "verdict": "previous_only"}
        keep.append(i)
        finals.append(final)
        entries.append(entry)
        why[final] += 1
    if not keep:
        why["no_facts_left"] += 1
        return None, why
    facts = [fact_line(edges[i]) for i in keep]
    record = {
        "prompt_name": PROMPT_NAME,
        "messages": [{"role": "system", "content": VERIFIER_INSTRUCTIONS},
                     {"role": "user", "content": verifier_user(rec, facts)},
                     {"role": "assistant",
                      "content": json.dumps({"labels": entries}, ensure_ascii=False)}],
        "meta": {"call_id": rec["id"], "group": rec["group"], "edge_index": keep,
                 "final": finals, "categories": [e.get("category") for e in entries],
                 "facts": facts, "current": current},
    }
    return record, why


def split_name(group: str, val_fraction: float, dev_fraction: float, seed: str) -> str:
    if split_of(group, val_fraction) == "val":
        return "test"
    h = int(hashlib.sha256(f"{seed}:{group}".encode()).hexdigest()[:8], 16) / 0xFFFFFFFF
    return "dev" if h < dev_fraction else "train"


def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser(prog="verifier_data")
    ap.add_argument("--capture", type=Path, action="append", required=True)
    ap.add_argument("--labels", type=Path, required=True)
    ap.add_argument("--recheck", type=Path, required=True)
    ap.add_argument("--out", type=Path, required=True)
    ap.add_argument("--val-fraction", type=float, default=0.2)
    ap.add_argument("--dev-fraction", type=float, default=0.05)
    ap.add_argument("--seed", default="20261027")
    a = ap.parse_args(argv)
    recs = read_records(a.capture)
    ids = [r["id"] for r in recs]
    labels = load_answers(AnswerStore(a.labels), "label", ids)
    rechecks = load_recheck(AnswerStore(a.recheck), ids)
    rows: dict[str, list[dict]] = {s: [] for s in SPLIT_FILES}
    facts: dict[str, Counter] = {s: Counter() for s in SPLIT_FILES}
    skipped: Counter = Counter()
    for rec in recs:
        lab = labels.get(rec["id"])
        if lab is None:
            skipped["unlabelled"] += 1
            continue
        record, why = build_record(rec, lab, rechecks.get(rec["id"], {}))
        split = split_name(rec["group"], a.val_fraction, a.dev_fraction, a.seed)
        facts[split].update(why)
        if record is None:
            skipped.update(k for k in why if k in ("label_count_mismatch", "no_facts_left"))
            continue
        rows[split].append(record)
    a.out.mkdir(parents=True, exist_ok=True)
    for split, name in SPLIT_FILES.items():
        with (a.out / name).open("w", encoding="utf-8") as fh:
            for r in rows[split]:
                fh.write(json.dumps(r, ensure_ascii=False) + "\n")
    summary = {"replies": len(recs), "records": {s: len(v) for s, v in rows.items()},
               "skipped": dict(skipped), "facts": {s: dict(c) for s, c in facts.items()},
               "groups": {s: len({r["meta"]["group"] for r in v}) for s, v in rows.items()}}
    (a.out / "summary.json").write_text(json.dumps(summary, indent=2))
    print(json.dumps(summary, indent=2))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
def _rec(cid: str, final: list[str], cats: list | None = None) -> dict:
    return {"meta": {"call_id": cid, "final": final,
                     "categories": cats or [None] * len(final),
                     "facts": [f"S{i} -> T{i}: fact {i}" for i in range(len(final))],
                     "current": CUR}}


def _reply(*labels: dict) -> str:
    return json.dumps({"labels": [{"n": n, **lab} for n, lab in enumerate(labels, 1)]})


ST = {"verdict": "stated", "quote": Q}
UN = {"verdict": "unsupported", "category": "over_inference"}
PO = {"verdict": "previous_only"}


def test_parse_reply_accepts_a_good_reply_in_any_entry_order() -> None:
    text = json.dumps({"labels": [{"n": 2, **UN}, {"n": 1, **ST}]})
    got = ve.parse_reply(text, 2)
    assert got is not None and [g["verdict"] for g in got] == ["stated", "unsupported"]


def test_parse_reply_rejects_fences_prose_and_empty() -> None:
    good = _reply(ST)
    for bad in ("```json\n" + good + "\n```", good + " Done.", "", "   ", "null"):
        assert ve.parse_reply(bad, 1) is None, bad


def test_parse_reply_rejects_bad_numbering_and_verdicts() -> None:
    assert ve.parse_reply(json.dumps({"labels": [{"n": 1, **ST}, {"n": 1, **ST}]}), 2) is None
    assert ve.parse_reply(json.dumps({"labels": [{"n": 1, **ST}, {"n": 3, **ST}]}), 2) is None

def test_score_metrics_and_bar() -> None:

                 [None, "wrong_detail", None]),
```

```python
"""Fact-verifier scoring (spec docs/superpowers/specs/2026-10-27-fact-verifier-design.md
sections 5-6). Local, free: reads the dataset's test.jsonl and the notebook's predictions.

    uv run --extra dev python -m scripts.distill.verifier_eval --data D/verifier1 \\
        --predictions D/verifier1/test_predictions.jsonl --out D/verifier1/report.json

A reply that is not exactly the JSON the model was trained to write -- including an empty
reply, a code fence or trailing prose -- is a parse failure and keeps every fact
(production fails open). A missing reply counts the same way.

P1 drops a fact on "unsupported", or on "stated" with a quote that is not word for word in
the CURRENT MESSAGE. P2 drops on "unsupported" only. "previous_only" is kept by both.
Exit code 0 when a policy passes the bar, 1 otherwise.
"""
from __future__ import annotations

import argparse
import json
import random
import re
from collections import Counter
from pathlib import Path

from scripts.distill.dpo_coverage import norm_ws, quote_ok
from scripts.distill.dpo_pairs import VERDICTS

MIN_CATCH = 0.50
MAX_FALSE_DROP = 0.02
MAX_PARSE_FAIL = 0.01
POLICIES = ("P1", "P2")
_WORD = re.compile(r"[a-z0-9][a-z0-9.\-_/]*")
STOPWORDS = frozenset("""a an and are as at be by can for from has have in is it its may of on or
that the this to via was were when which with without you your not also into only use used uses
using supports support supported""".split())


def parse_reply(text: str, n: int) -> list[dict] | None:
    try:
        obj = json.loads(text)
    except (TypeError, ValueError):
        return None
    labels = obj.get("labels") if isinstance(obj, dict) else None
    if not isinstance(labels, list) or len(labels) != n:
        return None
    out: list[dict | None] = [None] * n
    for lab in labels:
        k = lab.get("n") if isinstance(lab, dict) else None
        if type(k) is not int or not 1 <= k <= n or out[k - 1] is not None:
            return None
        if lab.get("verdict") not in VERDICTS:
            return None
        out[k - 1] = lab
    return [lab for lab in out if lab is not None]


def drops(parsed: list[dict] | None, current: str, policy: str, n: int) -> list[bool]:
    if parsed is None:
        return [False] * n
    out = []
    for lab in parsed:
        bad_quote = lab["verdict"] == "stated" and not quote_ok(lab.get("quote"), current)
        out.append(lab["verdict"] == "unsupported" or (policy == "P1" and bad_quote))
    return out


def read_predictions(path: Path) -> tuple[dict[str, str], int]:
    replies: dict[str, str] = {}
    dupes = 0
    for line in Path(path).read_text(encoding="utf-8").splitlines():
        if not line.strip():
            continue
        row = json.loads(line)
        if row["call_id"] in replies:
            dupes += 1
            continue
        replies[row["call_id"]] = row["reply"]
    return replies, dupes


def _reply_counts(rec: dict, dropped: list[bool]) -> Counter:
    c: Counter = Counter()
    for final, cat, d in zip(rec["meta"]["final"], rec["meta"]["categories"], dropped):
        c[final] += 1
        c[f"{final}_dropped"] += d
        if final == "confirmed":
            c[f"cat:{cat}"] += 1
            c[f"cat:{cat}_dropped"] += d
    return c


def _share(c: Counter, key: str) -> float:
    return c[f"{key}_dropped"] / c[key] if c[key] else 0.0


def score(records: list[dict], replies: dict[str, str], policy: str, resamples: int = 10_000,
          seed: int = 20261027) -> dict:
    per_reply: list[Counter] = []
    missing = failed = 0
    for rec in records:
        n = len(rec["meta"]["final"])
        text = replies.get(rec["meta"]["call_id"])
        parsed = parse_reply(text, n) if text is not None else None
        missing += text is None
        failed += parsed is None
        per_reply.append(_reply_counts(rec, drops(parsed, rec["meta"]["current"], policy, n)))
    tot: Counter = sum(per_reply, Counter())
    rng = random.Random(seed)
    catches, false_drops = [], []
    for _ in range(resamples):
        s: Counter = sum((per_reply[rng.randrange(len(per_reply))] for _ in per_reply), Counter())
        catches.append(_share(s, "confirmed"))
        false_drops.append(_share(s, "stated"))
    catches.sort()
    false_drops.sort()
    ci = lambda xs: [xs[int(0.025 * len(xs))], xs[min(int(0.975 * len(xs)), len(xs) - 1)]]
    cats = sorted(k[4:] for k in tot if k.startswith("cat:") and not k.endswith("_dropped"))
    return {
        "policy": policy, "replies": len(records),
        "catch": _share(tot, "confirmed"), "catch_ci": ci(catches),
        "false_drop": _share(tot, "stated"), "false_drop_ci": ci(false_drops),
        "previous_only_dropped": _share(tot, "previous_only"),
        "parse_fail": failed / len(records) if records else 0.0,
        "catch_by_category": {c: _share(tot, f"cat:{c}") for c in cats},
        "counts": {"confirmed": tot["confirmed"], "stated": tot["stated"],
                   "previous_only": tot["previous_only"], "missing": missing,
                   "parse_failed": failed},
    }


def passes(m: dict) -> tuple[bool, list[str]]:
    why = []
    if m["catch"] < MIN_CATCH:
        why.append(f"catch {m['catch']:.3f} < {MIN_CATCH}")
    if m["false_drop"] > MAX_FALSE_DROP:
        why.append(f"false drops {m['false_drop']:.3f} > {MAX_FALSE_DROP}")
    if m["parse_fail"] > MAX_PARSE_FAIL:
        why.append(f"parse failures {m['parse_fail']:.3f} > {MAX_PARSE_FAIL}")
    return not why, why


def _words(text: str) -> set[str]:
    return {w.rstrip(".").removesuffix("s") for w in _WORD.findall(norm_ws(text).lower())}


def lexical_drops(record: dict, threshold: float) -> list[bool]:
    """Code-only baseline: drop a fact when under `threshold` of its distinctive words
    (outside its two entity names and the stopwords) occur in the CURRENT MESSAGE."""
    current = _words(record["meta"]["current"])
    out = []
    for fact in record["meta"]["facts"]:
        names, _, text = fact.partition(": ")
        words = _words(text) - _words(names.replace(" -> ", " ")) - STOPWORDS
        out.append(bool(words) and len(words & current) / len(words) < threshold)
    return out


def _lexical_totals(records: list[dict], threshold: float) -> Counter:
    return sum((_reply_counts(r, lexical_drops(r, threshold)) for r in records), Counter())


def tune_threshold(records: list[dict]) -> float:
    """The threshold with the best catch whose false drops stay within the bar (train)."""
    best, best_catch = 0.0, -1.0
    for t in (i / 20 for i in range(21)):
        tot = _lexical_totals(records, t)
        if _share(tot, "stated") <= MAX_FALSE_DROP and _share(tot, "confirmed") > best_catch:
            best, best_catch = t, _share(tot, "confirmed")
    return best


def _read_jsonl(path: Path) -> list[dict]:
    return [json.loads(x) for x in path.read_text(encoding="utf-8").splitlines() if x.strip()]


def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser(prog="verifier_eval")
    ap.add_argument("--data", type=Path, required=True, help="dir with train.jsonl, test.jsonl")
    ap.add_argument("--predictions", type=Path, required=True)
    ap.add_argument("--out", type=Path, required=True)
    ap.add_argument("--resamples", type=int, default=10_000)
    a = ap.parse_args(argv)
    test = _read_jsonl(a.data / "test.jsonl")
    replies, dupes = read_predictions(a.predictions)
    policies = {p: score(test, replies, p, resamples=a.resamples) for p in POLICIES}
    verdicts = {p: passes(m) for p, m in policies.items()}
    passing = [p for p in POLICIES if verdicts[p][0]]
    threshold = tune_threshold(_read_jsonl(a.data / "train.jsonl"))
    base = _lexical_totals(test, threshold)
    report = {
        "passed": bool(passing), "policy": passing[0] if passing else None,
        "policies": {p: {**m, "passed": verdicts[p][0], "why": verdicts[p][1]}
                     for p, m in policies.items()},
        "duplicate_predictions": dupes,
        "baseline": {"threshold": threshold, "catch": _share(base, "confirmed"),
                     "false_drop": _share(base, "stated")},
        "bar": {"MIN_CATCH": MIN_CATCH, "MAX_FALSE_DROP": MAX_FALSE_DROP,
                "MAX_PARSE_FAIL": MAX_PARSE_FAIL},
    }
    a.out.write_text(json.dumps(report, indent=2))
    for p, m in policies.items():
        print(f"{p}: catch {m['catch']:.3f} {m['catch_ci']}, false drops {m['false_drop']:.3f} "
              f"{m['false_drop_ci']}, parse failures {m['parse_fail']:.3f} -> "
              f"{'PASS' if verdicts[p][0] else 'FAIL ' + '; '.join(verdicts[p][1])}")
    print(f"baseline (threshold {threshold}): catch {report['baseline']['catch']:.3f}, "
          f"false drops {report['baseline']['false_drop']:.3f}")
    return 0 if passing else 1


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
"""Verifier checkpoint selection (spec 2026-10-27-fact-verifier-design.md section 4): the
lowest dev loss, and an early stop once the last `patience` evals all sit above the best
before them (SFT v2 overfitted after about half an epoch). build_verifier_nb.py embeds this
module verbatim in the notebook: the unit tests and Colab run the same code."""


def dev_losses(log_history):
    """(step, eval_loss) per eval, sorted, one per step (a resumed run repeats some)."""
    by_step = {int(h["step"]): float(h["eval_loss"]) for h in log_history if "eval_loss" in h}
    return sorted(by_step.items())


def should_stop(losses, patience):
    return len(losses) > patience and min(losses[-patience:]) > min(losses[:-patience])


def select_dev_step(log_history):
    """The step with the lowest dev loss (the earlier on a tie), or None with no eval."""
    series = dev_losses(log_history)
    return min(series, key=lambda sv: (sv[1], sv[0]))[0] if series else None
```
